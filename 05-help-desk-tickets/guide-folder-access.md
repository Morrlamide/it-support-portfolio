# Folder access: how it works and how to ask for it

> [!NOTE]
> **Simulated Work.** A guide written for the fictional Corestack office. It is based on what I learned in [Project 01](../01-windows-accounts-permissions/README.md).

## How folder access works
Each folder has a list of who may open it and what they may do. Two levels matter most:
- **Read:** you can open the folder and read the files, but you cannot add or change anything.
- **Modify:** you can also add, change and delete files.

Most people only need Read or Modify. Giving only what someone needs keeps everyone's files safe.

## How to ask for access
Send IT a request with:
1. **The folder name** and where it is.
2. **Who needs access.** Give their name, not a shared account.
3. **What they need to do:** only look at files (Read), or add and change them (Modify).
4. **Why**, and for how long if it is temporary.
5. **Who approves it**, such as your team lead.

## What IT will do
- Check that the request is approved.
- Give access to the person's own account, with only the level asked for.
- Test it using that account.

## What you should do afterwards
1. Open the folder and check you can see the files.
2. If you asked for Modify, try adding a file or a folder.
3. Tell IT if anything does not work, and what message you saw.

## Passwords and accounts
- Always use your own account. Never share your password.
- IT should never need your password. If a new account is made for you, set your own password when you first sign in.

## If you can see a folder but not open it
You will usually see a message about permission. Do not try to work around it. Send IT a request as above.
