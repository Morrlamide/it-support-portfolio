# IT Support Portfolio

Hands-on IT support practice projects, built on my own Windows laptop. Each project folder has step-by-step commands, screenshots, the problems I hit and how I fixed them, and what I could not verify.

> [!NOTE]
> All projects are **Simulated Work**: practice scenarios on my own machine. No real employer, client or patient data is used. Computer and account names are real and left visible; network identifiers (IPs, MAC addresses, Wi-Fi names) are redacted.
